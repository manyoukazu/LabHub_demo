# LabHub — 研究室のアイデアストック

研究室内の研究（青）、先輩・教授のアイデア（緑）、外部の研究（黄）を保存し、関連づけて探索するツールです。Cloudflare Workers + D1 で動作します。

## ローカルで開く

Node.js 22 以上を使用します。Windows PowerShell では `npm.cmd` を使うと実行ポリシーによる `npm.ps1` のエラーを避けられます。

```powershell
npm.cmd install
npm.cmd run db:local
npm.cmd run dev
```

表示された URL（通常 http://localhost:8787）をブラウザで開いてください。`file://` で HTML を直接開く方法には対応していません。

ローカルは `.dev.vars` の `APP_MODE=demo` によってブラウザ保存のデモで開きます。本番の `APP_MODE=shared` ではサンプルを表示せず、アクセスキーで D1 の共有ストックを開きます。サンプル 11 件は説明用の架空データで、実在の研究室メンバーや実証済みの研究計画ではありません。実在する外部サービス・論文への参考リンクは含みます。元の Google ドキュメントを公開・同期する機能はありません。

## 試せること

- グラフと一覧の切り替え、詳細の表示
- 3 分類の絞り込み、キーワード・タグ・人の検索
- 追加・編集・削除、タグ、参考 URL、関連ストックの登録
- 共通タグまたは明示した関連を線で表示、ノードの移動と拡大縮小
- お気に入り（このブラウザに保存）、JSON 書き出し
- 狭い画面ではグラフの下に詳細を表示

デモのストックは localStorage に保存します。同じ URL と同じブラウザで開くと残ります。ブラウザのデータ削除やプライベートブラウズ終了で失われるため、必要な記録は「書き出す」で保存してください。お気に入りとノード位置はこのブラウザに保存され、研究室全員の共有情報ではありません。ノード位置は移動を終えると自動保存され、再読み込み後も復元されます。デモと共有モードの配置は別々に保存します。JSON 書き出しにノード位置は含みません。

## ローカル D1 を試す

`.dev.vars` の `LAB_TOKEN` を設定し、サーバーを起動します。この作業環境にはローカル専用の `local-development-key` を設定してあります。再セットアップ時は `.dev.vars.example` を `.dev.vars` にコピーできます。これは本番では使わないでください。

画面右上の歯車 → アクセスキーを入力 → 「共有モードに接続」。ローカル実行中の共有モードは `.wrangler/state/` 内のローカル D1 を使います。Cloudflare アカウントやインターネット接続は保存処理に不要です。DB は空で始まり、デモのサンプルは自動転送されません。

共有モードのキーはタブのメモリに保持します。再読み込み後、ローカルではデモに戻り、本番ではアクセスキーの入力画面に戻ります。再接続すると D1 の記録を確認できます。本番ではデモへの切り替えを表示しません。キー未設定・不一致では API が読み書きを拒否します。試作の認証は研究室共通キーであり、個人アカウントや権限管理は未実装です。共有データは操作時・再接続時に取得し、リアルタイム同期はしません。同時編集は最後の保存が優先されます。グラフは絞り込み後の先頭 40 件まで、共有モード全体は 2,000 件までの試作仕様です。

## 検証

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run test:browser
```

ブラウザテストは localhost:8787 の開発サーバーと、インストール済み Google Chrome を使います。テストは独立したブラウザコンテキストで実行し、作成した D1 のテスト記録を後片付けします。

## Cloudflare に配置する

構成は静的アセット + Cloudflare Workers の API + D1（SQLite）。画面はビルド不要です。本番への配置は以下の手順です。ローカル DB と本番 DB は別で、ローカルデータの自動転送は行いません。

1. `node scripts/wrangler.mjs login`
2. `node scripts/wrangler.mjs d1 create labhub-ideas`
3. 返された database_id を `wrangler.jsonc` の仮 ID と置き換える
4. `npm.cmd run db:remote`
5. `node scripts/wrangler.mjs secret put LAB_TOKEN` で本番用の長くランダムなキーを対話入力して設定（ローカル用のキーは使わない）
6. `npm.cmd run deploy`

アクセスキーはチャットやソースコードへ貼らず、Wrangler の対話入力または Cloudflare ダッシュボードの Worker → Settings → Variables and Secrets から設定してください。キーを知らない利用者にも画面の HTML は配信しますが、メモの読み書き API はキーがないと利用できません。

本運用に合わせて個人認証・アクセス制御、競合検知、ページ分割、バックアップ運用を追加できます。現段階ではファイル添付や AI 自動生成はありません。

無料枠・休止については [Cloudflare の調査メモ](docs/cloudflare-free-plan.md) を参照してください。
